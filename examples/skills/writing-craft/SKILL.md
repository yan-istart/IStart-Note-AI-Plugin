# 通用写作规范

## 写作目标

- 先判断当前任务是推进情节、解释概念、制造悬念，还是完成论证。
- 不重复已有信息，不复述用户刚刚给出的原文。
- 不确定事实时保持克制，不编造人物、数据或来源。

## 叙事与论证

- 场景优先于概述：用动作、对话、细节和因果推进。
- 每个段落只承担一个主要功能。
- 避免空泛形容词堆砌和重复解释。
- 结尾应当推动下一段、下一章或下一步论证，而不是总结全文。

## 修改检查

1. 是否有重复信息或同义反复？
2. 人物行为是否符合动机与已有设定？
3. 段落之间是否有清晰的因果或转折？
4. 结尾是否留下继续阅读或继续论证的动力？
