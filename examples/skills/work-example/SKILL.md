# 《示例作品》写作规范

## 事实来源

写作前以下列文件为准，不要在本 Skill 中重复剧情：

- `_作品.md`：作品简介与文风基调
- `_大纲.md`：章节梗概
- `_角色/`：人物设定
- `_设定/`：世界观与规则

## 叙事视角

- 第三人称限知，主要跟随主角。
- 不进入其他角色内心，除非章节明确切换视角。

## 文风

- 短句为主，描写克制。
- 恐怖感来自信息缺失和不确定性，不靠血腥堆砌。
- 避免网络流行语、作者旁白和总结句。

## 禁止

- 不新增未登记的能力体系。
- 不让角色说出与其背景不符的台词。
- 不用一句话概括刚刚发生的整章剧情。

## 续写前检查

1. 本章梗概是否已经推进？
2. 出场人物是否与角色卡一致？
3. 语言是否符合文风基调？
4. 是否给下一章留下自然的钩子？
